### New

- Collection folders now show their author's animated covers and drifting
  backdrops, playing only while they're on screen.
- A collection folder can carry its own hero video, which plays as its header.
- A folder opens its catalogs as named tabs, with a merged "All" tab that
  interleaves them. A source that no longer has an addon behind it is dropped
  instead of showing a tab that can only fail.
- Pressing a tab you're already on takes you back to that tab's top level.

### Bug fixes

- The "Who's watching?" profile picker is centred on wide windows instead of
  hugging the left edge.
